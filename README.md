# WebGonex Freelancer Portfolio

> **"Ideas into Digital Experiences."**
> A premium, fully responsive, motion-rich creative freelancer portfolio website for **WebGonex** by **Harsha T**.

---

## 🚀 Overview

Built with React 19, TypeScript, and modern styling, this website faithfully implements the brand identity from the **WebGonex launch poster** and font styling inspired by modern geometric editorial typography (**Absans** / Syne / Plus Jakarta Sans).

### Key Features
- **Cinematic Flash / Intro Sequence:** Animated logo reveal, red light sweep, Squares grid fade, and transition.
- **Custom Squares Background Canvas:** Interactive canvas with responsive resizing, diagonal motion, and hover glow effects.
- **Resume-Accurate Content:** Accurate personal details for Harsha T (B.Voc in Software and Application Development, 8.4 CGPA, AWS fundamentals, 2 deployed production projects).
- **Interactive Project Showcase:** Slider and Grid view modes with rich architectural breakdowns and modal specifications.
- **Services & Skills Matrix:** 6 categorized services with direct quote linking, plus categorized technology stack with zero fabricated metrics.
- **Freelancer Collaboration Form:** Interactive form with client-side validation and direct mailto fallback dispatch.
- **Accessibility & Motion Control:** Full `prefers-reduced-motion` support plus user-facing motion toggle in navigation.

---

## 🛠️ Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Vite development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview the production build:
   ```bash
   npm run preview
   ```
